# Evaluate sparsity in data over time in plot format

Evaluate sparsity in data over time in plot format

## Usage

``` r
sparsplot(project, x = NULL)
```

## Arguments

- project:

  String, name of project.

- x:

  Output from `sparsetable`. If `x` is null, the sparsity table will be
  pulled from the output folder if it exists.

## Details

Returns a plot of sparsity values over time. Requires sparsity table
generated by `sparsetable`.
