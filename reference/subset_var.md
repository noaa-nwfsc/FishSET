# Subset \`MainDataTable\` by variable

Subset \`MainDataTable\` by variable

## Usage

``` r
subset_var(dataset, filter_by = NULL, filter_value = NULL, filter_expr = NULL)
```

## Arguments

- dataset:

  dataset \`MainDataTable\` to filter.

- filter_by:

  String, name of variable used to subset \`MainDataTable\`.

- filter_value:

  Vector of values to subset by (inclusive).

- filter_expr:

  String, a valid R expression used to subset \`MainDataTable\`.
