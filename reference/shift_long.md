# Shift longitude predicate Detects whether longitude coordinates should be re-centered to Pacific view

Shift longitude predicate Detects whether longitude coordinates should
be re-centered to Pacific view

## Usage

``` r
shift_long(spat)
```

## Arguments

- spat:

  Spatial data to check.

## Value

`TRUE` if longitude should be shifted to pacific view (i.e. any
longitude values \< 0).
