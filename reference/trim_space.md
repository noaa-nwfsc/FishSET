# trim space function

trim space function

## Usage

``` r
trim_space(
  x,
  what = c("both", "leading", "trailing", "none"),
  space.regex = "[:space:]",
  ...
)
```

## Arguments

- x:

  variable of interest

- what:

  Choices are both, leading, trailing, none

- space.regex:

  Default set to \[:space:\]

- ...:

  Additional arguments
