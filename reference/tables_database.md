# View names of project tables

Wrapper for
[`dbListTables`](https://dbi.r-dbi.org/reference/dbListTables.html).
View names of tables in a project's FishSET database.

## Usage

``` r
tables_database(project)
```

## Arguments

- project:

  Project name

## Examples

``` r
if (FALSE) { # \dontrun{
tables_database('pollock')
} # }
```
