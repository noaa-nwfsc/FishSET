# View list of MainDataTables in FishSET database

View list of MainDataTables in FishSET database

## Usage

``` r
main_tables(project, show_all = TRUE)
```

## Arguments

- project:

  A project name to filter main tables by.

- show_all:

  Logical, whether to show all main tables (including raw and final
  tables) or just editable tables.

## Examples

``` r
if (FALSE) { # \dontrun{
main_tables("pollock")
} # }
```
