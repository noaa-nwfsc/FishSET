# Add date to ggplot title

Add date to ggplot title

## Usage

``` r
date_title(plot, filter_date, date_value)
```

## Arguments

- plot:

  ggplot2 plot object to add new title to.

- filter_date:

  The `filter_date` parameter in function.

- date_value:

  The values used to filter the data table used in plot.

## Value

A plot with the year, month, or year-month included in tittle.
