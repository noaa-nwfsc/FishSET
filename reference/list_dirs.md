# Find directories

Find directories

## Usage

``` r
list_dirs(
  path = ".",
  pattern = NULL,
  all.dirs = FALSE,
  full.names = FALSE,
  ignore.case = FALSE
)
```

## Arguments

- path:

  file path

- pattern:

  Use to define specific dirs to search for

- all.dirs:

  Logical

- full.names:

  Logical, Full name or directory name

- ignore.case:

  Logical
