# Labeling function for saving grid files

Labeling function for saving grid files

## Usage

``` r
grid_lab_helper(project, grid_info, grid_log = NULL, mod_type = "combine")
```

## Arguments

- project:

  Name of project.

- grid_info:

  List containing grid information.

- grid_log:

  Optional, the grid log. if `NULL`, uses names from `grid_info`.

- mod_type:

  String, "combine" for combined map files or "edit" for edited map
  files.
