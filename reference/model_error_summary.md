# Retrieve most recent summary of model error

Retrieve most recent summary of model error

## Usage

``` r
model_error_summary(project, output = "print")
```

## Arguments

- project:

  Name of project

- output:

  Output type. "print" returns formatted notes. "table" returns a
  dataframe. "print" is recommended for displaying summary table in a
  report.

## Examples

``` r
if (FALSE) { # \dontrun{
model_error_summary("pollock")
} # }
```
