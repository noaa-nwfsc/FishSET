# Convert decimal minutes/seconds to degrees

Convert decimal minutes/seconds to degrees

## Usage

``` r
dms_to_dd(x)
```

## Arguments

- x:

  Latitude or longitude vector.

## Examples

``` r
if (FALSE) { # \dontrun{
pollockMainDataTable$LonLat_START_LAT <- dms_to_dd(pollockMainDataTable$LonLat_START_LAT)
} # }
```
