# Print meta tables by project and/or type

Print meta tables by project and/or type

## Usage

``` r
meta_tables(project, tab.type = NULL)
```

## Arguments

- project:

  Name of project.

- tab.type:

  String, table type. Optional, used to filter output. Options include
  "main", "spat" (spatial), "port", "grid" (gridded), and "aux"
  (auxiliary).
