# Find numeric columns in data frame

Find numeric columns in data frame

## Usage

``` r
numeric_cols(dat, out = "names")
```

## Arguments

- dat:

  MainDataTable, dataframe, or list to check.

- out:

  Whether to return the column `"names"` (the default) or a logical
  vector (`"logical"`).

## Examples

``` r
if (FALSE) { # \dontrun{
numeric_cols(pollockMainDataTable)
} # }
```
