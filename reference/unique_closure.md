# Check for unique closure scenarios

Check for unique closure scenarios

## Usage

``` r
unique_closure(project, c_list, ind = TRUE)
```

## Arguments

- project:

  Name of project

- c_list:

  List of closure scenarios to check.

- ind:

  Logical, whether to return an index of unique closure scenarios from
  `c_list` or a single TRUE/FALSE value indicating that one or more
  closure scenarios are unique.
