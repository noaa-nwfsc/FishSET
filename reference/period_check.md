# Check for valid period

Check for valid period

## Usage

``` r
period_check(period, date)
```

## Arguments

- period:

  String, name of period to create. This is used by fleet functions to
  summarize data by period.

- date:

  String, name of date variable used to create period variable.

## Value

A period code used to format `date`. Assign output to a variable when
used inside a function.
