# Unserialize special tables in FishSET DB

Unserialize special tables in FishSET DB

## Usage

``` r
unserialize_table(table, project)
```

## Arguments

- table:

  The name of the special table to unserialize. Special tables include
  alternative choice matrix output, expected catch matrix output, the
  model data list, and the prediction output.

- project:

  Name of project.
