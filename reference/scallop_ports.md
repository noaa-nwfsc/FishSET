# Ports from the NE scallop fishery

A dataset containing the names and lat/lon coordinates of ports used in
the US northeast scallop fishery.

## Usage

``` r
scallop_ports
```

## Format

A data frame (tibble) with 40 observations and 3 variables.  
  
\[,1\] Port names  
\[,2\] Longitude  
\[,3\] Latitude
