# Returns the location of the log folder

Returns the location of the log folder

## Usage

``` r
loclog(project)
```

## Arguments

- project:

  Project name

## Details

if loc2 is not in the working environment, then the default location is
use

## Examples

``` r
if (FALSE) { # \dontrun{
loclog('pollock') # will return log folder location for project pollock within the fishset package
} # }
```
