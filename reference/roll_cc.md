# Apply window_cc

Used by [`roll_catch()`](roll_catch.md) to count unique vessels within a
rolling window for multiple columns of catch.

## Usage

``` r
roll_cc(dat, k, align)
```

## Arguments

- dat:

  Dataframe used to calculate rolling catch.

- k:

  Window width.

- align:

  Window alignment.
