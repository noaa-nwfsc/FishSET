# Perfom quality check for `split_dat`

Perfom quality check for `split_dat`

## Usage

``` r
split_check(main, split, key, arg)
```

## Arguments

- main:

  String, column names from MainDataTable.

- split:

  String, column names from "split_by" argument.

- key:

  String, column names from "key" argument.

- arg:

  String, whether "aux" or "split_by" argument was used.
