# Create FishSET project settings

This function creates the project settings file located in the
project/doc folder.

## Usage

``` r
create_proj_settings(project)
```

## Details

The project settings file contains the confidentiality settings, the
file path to the user output folder, plot size (width by height in
inches), and table names used in the shiny app (for logging purposes).
