# Model checklist

Determines whether final data passes quality checks, that occurrence
points have been checked, that an alternative choice matrix has been
created, and if an expected catch/revenue matrix is required.

## Usage

``` r
checklist(project, modDesignTab = NULL)
```

## Arguments

- project:

  String, name of project.

- modDesignTab:

  The model design table. Only used in the FishSET app.
