# View

View

## Usage

``` r
view_lon_lat(dat, lon, lat, id = NULL, crs = 4326)
```

## Arguments

- dat:

  Data containing `lon` and `lat` columns.

- lon:

  Name of Longitude column.

- lat:

  Name of Lattitude column.

- id:

  Optional, name of an ID variable that is paired with `lon` and `lat`
  columns

- crs:

  Optional, coordinate reference system to use. Defaults to EPSG code
  4326 (WGS 84).
