# Pull data from latest project file

Pull data from latest project file

## Usage

``` r
get_latest_projectfile(project, mod.name)
```

## Arguments

- project:

  Project name

- mod.name:

  Model name

## Examples

``` r
if (FALSE) { # \dontrun{
get_latest_projectfile("pollock", "logit_mod1")
} # }
```
