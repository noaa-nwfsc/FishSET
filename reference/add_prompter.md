# Wrapper for prompter::add_prompt()

Wrapper for prompter::add_prompt()

## Usage

``` r
add_prompter(
  ui_element,
  position = "bottom",
  message = NULL,
  type = NULL,
  size = NULL,
  permanent = FALSE,
  rounded = FALSE,
  animate = TRUE,
  bounce = FALSE,
  arrow = TRUE,
  shadow = TRUE
)
```
